Safe Browser (Proctoring) — bu onlayn imtihon vaqtida foydalanuvchini aldash (cheating)dan himoyalash uchun ishlatiladigan maxsus brauzer yoki tizim.

Qisqacha mazmuni:

Safe Browser proctoring talabaning kompyuterini vaqtincha qat’iy nazorat rejimiga o‘tkazadi va imtihondan tashqari har qanday harakatni cheklaydi.

Asosiy vazifalari:

🔒 Boshqa sayt va dasturlarni bloklaydi (Google, Telegram, TeamViewer, AnyDesk va h.k.)

⌨️ Tugmalarni cheklaydi: Alt+Tab, Alt+F4, Win, Ctrl+C/V, PrintScreen

🖥 Faqat imtihon sahifasini ochishga ruxsat beradi

📸 Web-kamera orqali yuzni nazorat qiladi

👀 Ko‘z va bosh harakati, yon tomonga qarashni aniqlaydi

📱 Telefon yoki boshqa taqiqlangan obyektlarni aniqlaydi (AI orqali)

🎥 Ekranni yozib boradi (screen recording)

🌐 Internet uzilishi bo‘lsa log saqlaydi

Qayerda ishlatiladi:

Onlayn universitet imtihonlari

Sertifikatlash testlari

Masofaviy kirish imtihonlari

Proctoring tizimlari (Respondus, Safe Exam Browser, Proctorio va h.k.)

Texnik tomoni (qisqacha):

Maxsus Secure Browser (SEB)

WebCam + Screen monitoring

AI/ML (yuz, obyekt, harakat tahlili)

Serverga real-time log va video yuborish
